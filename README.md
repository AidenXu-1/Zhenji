# 帧集

帧集是一款面向 macOS 的本地截图、录屏与素材采集工具。它把截图编辑、滚动长图、文字提取、图片翻译、录屏编辑、采集卡和采集板放进一套连续工作流。

## 下载

[下载最新版本](https://github.com/AidenXu-1/Zhenji/releases/latest)

当前公开测试版仅支持：

- macOS 15 或更高版本
- Apple Silicon Mac（M1、M2、M3、M4 等）

推荐下载 DMG。ZIP 是备用安装包，两者包含同一版本的应用。

## 安装与首次打开

1. 下载并打开 `Zhenji-0.1.0-macOS-arm64.dmg`。
2. 把“帧集”拖入“应用程序”。
3. 由于当前版本没有经过 Apple 公证，macOS 可能阻止首次打开。
4. 打开“系统设置”→“隐私与安全性”，在“安全性”区域点击“仍要打开”，再确认一次。
5. 按应用内引导授予屏幕录制权限。只有使用对应录制功能时，才需要麦克风或摄像头权限。
6. macOS 授权后若功能没有立即生效，请退出并重新打开帧集。

“仍要打开”只处理首次启动拦截，不能代替屏幕录制、麦克风或摄像头隐私授权。

## 核心功能

- 智能区域、窗口与全屏截图
- 标注、圆角、阴影、固定截图与上次范围
- 滚动长图、OCR 文字提取、二维码识别
- 基于 Apple 本地能力的中、英、日、韩图片翻译
- 屏幕、麦克风、摄像头录制与本地编辑
- 采集卡、采集板和录制素材库
